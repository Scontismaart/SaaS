## 3) MOTION UPGRADE (motivato, transform/opacity only, ridotta-motion gating)

Tutto rispetta `prefers-reduced-motion` e non usa `window.addEventListener('scroll')` su state React (preferisco IntersectionObserver e CSS scroll-driven).

- **Scroll progress bar** in cima (gradiente oro, scaleX): wayfinding e hierarchy. Via CSS `animation-timeline: scroll(root)` con fallback rAF.
- **Parallax immagine brand** (sopra): CSS `animation-timeline: view()`, fallback statico.
- **Magnetic CTA**: hero primary e CTA finale si muovono leggermente verso il cursore (transform only, rAF-throttled, off in reduced-motion). Tactile feedback premium.
- **Refactor nav scroll-tint**: sostituisco l'attuale `window.addEventListener('scroll')` (bannato dalla skill) con un **IntersectionObserver sentinel** in cima alla pagina. Stesso effetto visivo, conforme.
- **Raffinamento reveal stagger** già presente (blur-up): conservo, assicuro stagger coerente.
- Verifico "motion claimed = motion shown": la pagina si muove davvero (hero drift, typing, counter, reveal, parallax nuovo, progress bar, magnetic).

## 4) DARK MODE (mandatory per consumer)

Oggi la landing è light-only. Aggiungo dark mode rispettando `prefers-color-scheme` (no toggle, nav resta pulita):
- Tailwind config: `darkMode: 'media'`.
- Palette dark: fondo `carbone2 #2A2826` / superfici `#1C1B1A` / testo `#F0EDE6` / accent **oro preservato** (coerenza brand).
- Applico `dark:` variant alle superfici chiave (body, nav, card, section bg, footer). Shape e accent lock restano identici in entrambi i modi.
